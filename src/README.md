# Source layout

The decompiled tree lives here: every one of the 7,862 matchable functions of
`Pirates!.exe` has a candidate definition under
`<subsystem>/<wave>/<wave>.cpp`, generated by `tools/merge_reconstruction.py`
from the per-wave manifests in `experiments/2026-11-08-source-reconstruction/out/`.
`reconstruction/manifest.json` maps every address to its subsystem, wave, and
source file; `reconstruction/INDEX.md` summarizes coverage.

## Tiers

1. **Verified units** — hand-maintained `*.cpp` files directly under a
   subsystem directory, each owning a declared unit in `build/units.json`
   with a byte-identical `tools/match.py` PASS against the shipped image:

   | File | Units | Addresses |
   |---|---|---|
   | `engine/setter_u32_00547610.cpp` | `tiny_547610` | `0x00547610` |
   | `engine/setter_u8_0054a9f0.cpp` | `tiny_54a9f0` | `0x0054a9f0` |
   | `engine/triple_copy_005366b0.cpp` | `tiny_5366b0` | `0x005366b0` |

2. **Decompiled candidates** — generated `<subsystem>/<wave>/<wave>.cpp`
   files (391 waves). **UNVERIFIED by byte-match**: they are faithful
   translations of the Ghidra 12.2 corpus, not proven original source. Each
   function carries its `// 0xADDR — observed shape` header; the shipped
   address remains the identity.

The toolchain is installed (`analysis/toolchain/`, driven by
`tools/wine-cl.sh`). Verify the verified tier with:

```sh
python3 tools/match.py check \
  --image "experiments/2026-11-08-target-identification/output/extracted/app/Pirates!.exe"
python3 tools/match.py compare --all \
  --image "experiments/2026-11-08-target-identification/output/extracted/app/Pirates!.exe"
```

## Subsystems

Generated waves are routed by the majority band of their addresses
(`findings/2026-11-08-team-decompilation.md`; labels are heuristic):

| Subsystem | Band ranges (inventory) | Content |
|---|---|---|
| `game/` | `0x401000–0x4c3690`, `0x4c3790–0x514090`, `0x591460–0x5dab60` | Firaxis game logic: startup/UI entry, options/encyclopedia, sailing/combat/colonies |
| `engine/` | `0x5141c0–0x54ada0`, `0x54ae10–0x5913a0`, `0x5db0a0–0x61003c`, `0x610165–0x672e90` | Gamebryo 10.1 (`NiMain`, `NiAnimation`, `NiCollision`, NiD3D shader wrappers), class-system support |
| `platform/` | (no whole band; Win32/Miles/Bink code is inside `game/` band 2 and `crt/` band 8 files) | Win32 initialization, Miles audio, Bink video, D3D9 loading |
| `crt/` | `0x672ecd–0x6bfc80` | bundled D3DX9 shader compiler `5.04.00.2904`, PNG/zlib codecs, MSVCR71 tail, EH funclets |

Rules:

- Verified-tier files must own at least one declared unit in `build/units.json`; a file without a claim is not part of the build.
- Generated wave files are owned by `reconstruction/manifest.json` (one claim per address, derived from the sources themselves by `tools/ingest_mass_reconstruction.py`); do not hand-edit them — fix the corpus/manifests and re-run the merge.
- File and symbol names describe recovered behavior. The shipped address remains the identity.
- A verified-tier file is added only with the flags and evidence that produce a PASS.
- Do not copy leaked or unlicensed engine source. Gamebryo 10.1 is proprietary; reconstruct from the shipped binary and public documentation.
